# Portfolio — Manda Germain

Site vitrine statique (HTML, CSS, JavaScript).

## Prévisualisation locale

Ouvrez `index.html` dans votre navigateur, ou servez le dossier avec un serveur local :

```bash
python -m http.server 8080
```

Puis visitez `http://localhost:8080`.

## Déploiement (GitHub Pages)

Le dépôt [mandagermain3-ai/mon-portfolio](https://github.com/mandagermain3-ai/mon-portfolio) se déploie automatiquement à chaque push sur `main`.

1. Sur GitHub : **Settings → Pages → Build and deployment → Source** : choisissez **GitHub Actions**.
2. Poussez vos changements sur `main` ; le workflow **Deploy GitHub Pages** publie le site.
3. L’URL sera affichée dans **Settings → Pages** (souvent `https://mandagermain3-ai.github.io/mon-portfolio/`).
